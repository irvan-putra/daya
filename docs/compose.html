daya compose

Describe a small app in words; get a daya recipe (JSON) out. Every route validates its output against the same web schema before showing it. Build the recipe into a working page with daya build recipe.json -o app.html (daya on GitHub). All daya examples

The deterministic route makes no network requests. The classifier route downloads a ~30 MB model+runtime and the in-page model route downloads the model from huggingface.co and its runtime from cdn.jsdelivr.net (they see the download, not your words); your description is processed by the model running in this page.
